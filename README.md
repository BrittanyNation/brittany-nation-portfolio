# Brittany Nation — Front-End Developer Portfolio

A single-page portfolio site for **Brittany Nation**, front-end developer.

## Tech

- HTML5 (semantic, accessible markup)
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Vanilla JavaScript — no frameworks, no build step

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure: nav, hero, about, skills, projects, contact, footer |
| `styles.css` | Custom extras: hero glow, reveal animations, skill pills, project cards |
| `script.js` | Mobile menu, smooth scroll offset, reveal-on-scroll, active nav highlighting |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server
```

## Sections

- **Hero** — name, title, one-line hook, CTAs
- **About** — career transition into web development, remote-ready
- **Skills** — HTML5, CSS3, JavaScript (ES6+), Tailwind CSS, React, Python, Git/GitHub, Responsive Design, REST APIs
- **Projects** — 9 open-source projects, each linking to its GitHub repo
- **Contact** — email, GitHub, LinkedIn
